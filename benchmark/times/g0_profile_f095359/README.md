## 판정 (P12_PLAN §3 G0-1)

1. **매핑 스레드**: LBA가 LM 사이클의 54~76% — 계획서 정찰의 논문 주장
   (Local BA 53~81%)이 이 저장소·arm64에서 그대로 재현된다. KF 처리량의
   지배 항목은 g2o 최적화다.
2. **루프 이벤트**: Essential Graph 249ms(이벤트의 97%) + GBA 평균 2.61초 —
   루프 정정 지연은 사실상 전부 g2o 시간이다.
3. **트래킹 스레드는 최적화 병목이 아니다**: 카메라 레이트 경로는 ORB
   추출이 우세(5.3~8.9ms), 포즈 최적화 포함 LM Track은 2.5~4.1ms. GTSAM이
   트래킹 레이트를 올려주지는 않는다 — 개선 표적은 KF 처리량과 루프 정정
   지연이다.
