# R-시리즈 최종 리포트 — 오픈소스 리팩토링 (R1–R6)

2026-08-11 ~ 2026-08-21 · 커밋 범위 3b14fb9 → 3ef590d · 전 스텝 완결

## 1. 배경과 방침

P-시리즈(P1–P11)가 bug-for-bug 보존 + 페어드 통계 게이트 체제로 진행되던 중,
사용자가 방향을 재정렬했다: **목표는 검증 장치가 아니라 오픈소스 리팩토링이다.**
이에 따라 P-시리즈 체제(페어드 게이트, TSAN 대장, FixLevel 플래그, 수명 프로브)를
동결하고 R-시리즈를 채택했다. 운영 원칙:

- **원본은 목표가 아니라 바닥**: 원본 자체가 덜 최적화된 시스템이므로, 개선(정확도·효율)은
  정당화가 필요 없고 원본보다 나빠질 때만 근거가 필요하다.
- **경량 검증**: 커밋당 빌드+스모크, 스텝당 스팟체크(비트 게이트·kitti07·MI 대역),
  시리즈 종결 시 5모드 대역 판정(원본 중앙값 −15%가 회귀 바닥).
- 합리적 수정은 그냥 적용하고 간단한 영문 주석을 남긴다.

## 3. 스텝별 요약 (상세 증거는 REFACTOR_PLAN.md 각 행)

- **R1 — 툴체인** (76ee5fb): Ubuntu 24.04/GCC13/C++20, 컴파일 낙진 수리, 비트 해시 재기록.
  대역 검증에서 3모드가 원본보다 우수(mono −26.7%). 부수 성과: stereo-inertial 골든이
  하루짜리 호조건 캡처였음을 판명, 23런 이력 중앙값(0.0394)으로 재베이스라인.
- **R2 — Eigen/Pangolin 서브모듈** (67d2aa4): `cmake/FindEigen3.cmake` 셰도잉으로
  우리/g2o/Pangolin 3계통 단일-Eigen 핀, 이미지에서 시스템 Eigen 제거(우회 시 즉시 실패).
- **R3 — DBoW2 업스트림 + 래퍼** (2f1ee42, −4,025줄): 포크 감사로 "텍스트 어휘 포맷 =
  저자 추가분, FORB 수치 동일"을 증명한 뒤 업스트림 서브모듈 + 상속 래퍼로 전환.
  바이너리 캐시 동승, Boost 직렬화 비침습 복원.
- **R4a — 픽스 승격 + 계측 은퇴** (534c739, −2,644줄): FixLevel 픽스 8종 무조건 적용,
  플래그 기계·LifetimeLedger 제거. 유닛은 무조건 동작 계약으로 재작성.
- **R4b — 스마트 포인터 이행** (0f64ff6 + 3ad8b4e): MapPoint 546 + KeyFrame 877 사이트.
  순환 절단 설계(관측 키 raw+스크럽 계약, 스패닝 트리 자식→부모 strong, IMU 사슬,
  약참조 루프/병합 엣지)는 OWNERSHIP.md 표로 문서화. ASan 풀런 무보고,
  .osa 아카이브 바이트 호환 유지.
- **R4c — 관용구 스위프** (7f33c20): 경고 450→17(우리 코드 0). 실버그: GeometricCamera
  가상 소멸자 부재, int-절단 abs.
- **R5 — Optimizer 분해 + g2o 빌더** (b63ab6b): 스크립트 주도 순수 이동(재조립 바이트 동일
  단언) 후 헬퍼 적용. 검증의 백미: equiv 하네스 전 레코드가 분해 전 아카이브와
  SHA256 바이트 동일 — 수치 무변경의 최강 증거.
- **R6 — 주석 코드 전수 심사** (5b282f8, −489줄): 197건 전원 업스트림 유래.
  유일한 구현(초기화 중 FrameDrawer 갱신)은 커밋 전 9-감사자 적대 diff 검증에서
  실블로커(스테일 mvIniMatches → 뷰어 스레드 OOB 가능)가 적발되어 원인 스크럽 +
  드로어 경계 가드로 수정 후 커밋.

## 5. 방법론적 교훈

1. **대역 이상치는 동야간 교차로만 판별된다.** 골든과의 단순 비교는 머신 상태
   (±20%)와 코드 회귀를 구분하지 못한다.
2. **바이트 동일 재조립 단언**은 대규모 코드 이동의 표준 절차로 정착시킬 가치가 있다
   (R5: 이동 검증과 의미 변경을 완전히 분리).
3. **적대적 diff 감사가 실제 결함을 잡는다.** R6의 9-감사자 검증은 "활성화는 무해"라는
   그럴듯한 결론 밑에 있던 유일한 실제 UB 경로를 찾아냈다.
4. **골든 자체를 의심하라.** R1의 stereo-inertial FAIL은 코드가 아니라 하루짜리
   골든이 문제였다.
