# Phase 7 리포트 — Tracking 계층 (2026-08-09)

## 접근 조정 (정찰 근거)

정찰(docs/P7_RECON.md)이 계획의 전제를 뒤집는 사실을 찾았다:
`LocalMapping::InitializeIMU`가 **다른 스레드에서** `mpTracker->mState`를
뮤텍스 없이 직접 쓴다(LocalMapping.cpp:1440). 상태머신이 Tracking 단독 소유가
아니므로, 계획서의 "State 패턴 분해"를 그대로 적용했다면 이 교차 스레드 전이가
소실됐을 것이다 — Remastered R-1 회귀와 같은 부류. 그래서 폴리모픽 재작성 대신
**캡슐화 + 전이 계측 + 골든 트레이스**로 방향을 바꿨다(사용자 승인).
