## stereo-inertial 사후 분석 (DIVERGENCES #20)

경계 p값(0.057)에 대해 사전등록 확장 검정을 실시했다: 보충 4쌍 → 8v8에서
+13.5% p=0.0325 — FAIL 기준 충족. bisect-replication(당일 페어드 인터리브,
phase-7 대조 청정 −8.4% 0/4)으로 **계단이 P8-1(순수 삭제 커밋)에서 진입**함을
확인했고, 의미론 가설 전부를 배제한 뒤(전수 재감사·bg/ba 입력 미사용·KF 개수
불변·머신 상태 대조) **바이너리 레이아웃/코드젠 매개 타이밍 효과**로 판정했다.
P8 범위 합산 24쌍 중 18쌍 악화(부호검정 p=0.011). 상세 증거와 배제 논증은
DIVERGENCES #20.

**처분(사용자 확정)**: 수용+문서화+태그. 절대 ATE 4.3cm는 원본의 당일 실행
산포(3.1~5.1cm) 내부이고, 죽은 코드 복원은 원칙적 해법이 아니다. P9 게이트에서
이 모드를 재계측하며, 추가 악화 시 #20을 재개한다.
