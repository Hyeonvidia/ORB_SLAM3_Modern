## 이 게이트가 증명하지 않는 것

- 병합 경로(MergeLocal/2)의 스레딩은 실전 미발현 — CV/조인 전환은
  by-construction+유닛 체크 수준
- GUI 메뉴 경로(menuStop→RequestShutdown)는 구조 검증만(headless 환경)
- Frame 객체 교차 레이스는 잔존(설계상 — P11 스마트포인터/수명 계약 재설계)
- 미드런 SIGINT 셧다운 주입은 예제 수정 필요라 스킵(한계 명기)

## 방법론 수확

- **TSAN 시그니처 대장 델타**가 "고치려던 것을 고쳤고 새로 안 망가뜨림"의
  증거 표준으로 정착 — 스텝 대장 6부가 저장소에 남음.
- **gcc-11 libtsan의 pthread_cond_clockwait 미인터셉트** 발견: timed CV wait는
  반드시 system_clock wait_until로 (코드에 do-not-modernize 주석 2곳).
  가짜 시그니처의 원시 스택 판독(동일 뮤텍스 양측 보유 = 논리 불가능)이
  판별 절차의 모범 사례.
- 경계 p값 선예화 규칙이 2번째로 작동(P8 SI → P10 mono) — 이제 게이트
  방법론의 상비 절차로 간주.
- 셧다운 품질의 정량 증거(TSAN atexit 에필로그 + 스레드 누수 0)는 조인
  사슬류 작업의 표준 증거로 재사용 가치.
